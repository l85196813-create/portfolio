# lmarchetti.com

Personal portfolio of Luca Marchetti. Plain HTML and CSS, no build step, served by GitHub Pages.

## Structure

- `index.html` — home
- `projects.html` — project list
- `projects/*.html` — one page per project
- `experience.html` — timeline, skills and CV download
- `contact.html` — contact links
- `assets/style.css` — all styles (dark and light theme variables at the top)
- `assets/theme.js` — theme toggle
- `assets/Luca_Marchetti_CV.pdf` — the CV (add it here)
- `CNAME` — custom domain for GitHub Pages

## Adding a project

1. Copy one of the files in `projects/` and edit its text.
2. Add a card for it in `projects.html` (and in `index.html` if it should be featured).
